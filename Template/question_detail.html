How do I implement a binary search algorithm in Python?

I'm struggling to understand how binary search works and how to implement it efficiently in Python. I understand the concept that it divides the search space in half each time, but I'm having trouble with the actual implementation. Could someone provide a clear explanation with code examples? Here's a clean implementation of binary search in Python: 
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1  # Element not found
The time complexity is O(log n) and space complexity is O(1) for the iterative version. The key insight is that we eliminate half of the remaining elements in each iteration.

I'd also recommend understanding the recursive approach: 
def binary_search_recursive(arr, target, left=0, right=None):
    if right is None:
        right = len(arr) - 1
    
    if left > right:
        return -1
    
    mid = (left + right) // 2
    
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, right)
    else:
        return binary_search_recursive(arr, target, left, mid - 1)
This recursive version has O(log n) time complexity but O(log n) space complexity due to the call stack.
